# Source attribution

This repository contains a derived catalog and experimental adapters for CTIConnect:

Cheng, Y., Liu, Y., Li, C., Song, D., & Gao, P. (2026). “CTIConnect: A Benchmark for Retrieval-Augmented LLMs over Heterogeneous Cyber Threat Intelligence.” KDD 2026. Official repository: https://github.com/peng-gao-lab/CTIConnect

The upstream CTIConnect code is MIT licensed and its released data is CC-BY-4.0. `data/cticonnect/catalog.jsonl` is derived from CTIConnect v1.0.0 and remains subject to the upstream data license.

The experiment design also builds on:

Cattan, A., Jacovi, A., Ram, O., Herzig, J., Aharoni, R., Goldshtein, S., Ofek, E., Szpektor, I., & Caciularu, A. (2025). “DRAGged into Conflicts: Detecting and Addressing Conflicting Sources in Search-Augmented LLMs.” arXiv:2506.08500v2.

No license is granted here for third-party papers beyond their original terms.
