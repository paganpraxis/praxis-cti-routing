# Imported CTIConnect catalog

`catalog.jsonl` is a derived, gold-bearing index of the official CTIConnect v1.0.0 release. It is licensed under the upstream CTIConnect data license (CC-BY-4.0) and should be attributed to Cheng et al., “CTIConnect: A Benchmark for Retrieval-Augmented LLMs over Heterogeneous Cyber Threat Intelligence,” KDD 2026.

Do not use this file as detector input. Its gold answers and source provenance are intentionally separated from `data/detector_input.jsonl`.

`import_summary.json` records the upstream manifest hash, release version, and verified task counts.
